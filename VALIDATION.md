# Verification

The test suite uses disposable data and synthetic scenarios. Run the source checks for the version you have checked out.

Use `npm run typecheck` and `npm test` to verify the TypeScript application. The Electron build uses `npm run build`.

The Rust assistant suite covers dated task creation, linked calendar entries, deadlines, retry safety and Undo. The Windows installer was exercised in a disposable guest for upgrade, v8 database migration, data retention and rollback. The unsigned candidate was blocked by Smart App Control on the target PC.
