# Original MYMIND workflow

The original planning workflow used horizontal month timelines, crossed-out past days, colored calendar notes, and project-based tasks. MYMIND preserves those capabilities in its own interface.

The project evolved into a local assistant for a calendar and task list. The assistant distinguishes questions from changes and shows a preview before saving changes. Planner records persist between sessions, while the conversational workspace starts fresh.
